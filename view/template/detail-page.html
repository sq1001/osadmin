简介

OSAdmin 是一个基于 Layui 的现代化后台管理系统框架，提供完整的权限管理、数据展示和系统配置功能。它采用 SPA 单页应用架构，支持多标签页切换、动态路由和组件化开发。

框架内置了用户管理、角色权限、系统设置等常用模块，开发者可以基于此快速搭建企业级后台系统。同时，OSAdmin 提供了丰富的页面模板和组件，覆盖了后台系统常见的布局场景。

本页面展示了详情页/文档页的布局模式，适合帮助文档、系统说明、配置向导等场景使用。左侧为固定导航，右侧为信息流内容，支持滚动联动高亮。

功能特性

权限管理
基于角色的细粒度权限控制，支持菜单、按钮级别的权限分配
SPA 路由
单页应用架构，支持动态路由和页面缓存，流畅切换无刷新
主题切换
支持亮色/暗色主题，CSS 变量驱动，一键切换全局风格
数据可视化
集成图表组件，支持柱状图、折线图、饼图等常见数据展示
系统配置
灵活的系统参数配置，支持运行时动态调整，无需重启服务
文件管理
支持多种文件上传方式，自动压缩、水印，统一文件管理

系统架构

OSAdmin 采用前后端分离架构，前端基于 Layui 组件库和自定义 SPA 框架，后端可对接任意 RESTful API 服务。

前端架构层次：

1. 核心层（Core）：SPA 路由引擎、权限控制、全局状态管理、主题系统

2. 组件层（Components）：基于 Layui 封装的业务组件，包括表格、表单、弹窗等

3. 页面层（Pages）：各功能模块的页面模板，支持动态加载和缓存

4. 数据层（Data）：统一的 AJAX 请求封装、数据格式化和错误处理

所有页面均使用 CSS 变量控制主题样式，框架自动注入 layui 资源，页面无需独立引入。页面结构统一使用 .page-content 作为外层容器，确保与框架布局的一致性。

配置说明

配置项 键名 默认值 说明

API 基础路径 apiBase /api 后端接口统一前缀
分页大小 pageSize 10 数据表格默认每页条数

主题模式 theme light 默认主题，可选 light/dark

部署指南

获取源码
从代码仓库克隆项目到本地：git clone https://github.com/example/osadmin.git
安装依赖
进入项目目录，安装前端构建工具依赖：npm install
修改配置
编辑 app.config.js，配置 API 地址、应用名称等参数
构建项目
执行构建命令生成生产环境文件：npm run build
部署上线
将构建产物部署到 Web 服务器（Nginx/Apache），配置反向代理指向后端 API 服务

接口文档

GET /api/users
获取用户列表，支持分页和筛选
请求参数：page(页码), limit(每页条数), keyword(搜索关键词) 响应格式：{ "code": 0, "data": { "list": [], "count": 100 } }
POST /api/users
创建新用户
请求体：{ "username": "string", "password": "string", "role": "string" } 响应格式：{ "code": 0, "msg": "创建成功" }
PUT /api/users/:id
更新用户信息
请求体：{ "nickname": "string", "email": "string", "status": "number" } 响应格式：{ "code": 0, "msg": "更新成功" }
DELETE /api/users/:id
删除指定用户
路径参数：id(用户ID) 响应格式：{ "code": 0, "msg": "删除成功" }

常见问题

如何修改系统默认主题？
在 app.config.js 中修改 theme 配置项，可选值为 light 或 dark。修改后刷新页面即可生效。也可以在页面顶部工具栏中手动切换主题。
如何添加新的页面路由？
在路由配置文件中添加新的路由项，指定路径、组件和权限标识。框架会自动在侧边栏菜单中生成对应的导航入口。新页面文件放置在 view/template/ 目录下即可。
如何对接后端 API？
修改 app.config.js 中的 apiBase 配置项为后端服务的实际地址。框架内置了统一的 AJAX 请求封装，自动处理 Token 注入和错误拦截。
页面加载缓慢如何优化？
1. 开启标签页缓存，避免重复加载；2. 使用构建工具压缩静态资源；3. 配置 CDN 加速；4. 后端接口增加分页查询，减少单次数据量。
